`Python` `FastAPI` `SQLAlchemy` `React` `Recharts`

Full-stack farm management platform built by a 5-person team — relational MySQL schema, an Express REST API, and a Wix-hosted frontend with interactive Google Maps field mapping and task tracking. Graded First Class. My role: database design and backend API development.
`Node.js` `Express` `MySQL` `REST API`
